# 台股獨立版本

台股使用 `/tw` 與 `/tw/stock/2330`；不修改美股 provider、篩選門檻、daily/history 或收藏。發布狀態以任務發布紀錄為準，此文件不是已部署證明。

## 資料與核對

- 官方公司名單、行情、月營收、一般業損益：TWSE 與 TPEx OpenAPI，規格為 https://openapi.twse.com.tw/v1/swagger.json 、https://www.tpex.org.tw/openapi/swagger.json 。名單交叉核對四位數公司候選，不從行情表直接納入 ETF/權證。
- 財報： https://mopsfin.twse.com.tw/ 財務比較平台的「綜合損益表(累計)」「現金流量表(累計)」。報表明示「金額單位：新台幣仟元」；解析器核對期間、公司代號、欄列形狀和合併口徑後換算新台幣元。
- 近四季（TTM）= 本期累計 + 上年度全年 − 上年同期累計。成長率再與前一年TTM比較，不把半年累計誤當單季。不同合併口徑、缺值、缺期間皆不通過。
- 當期累計營收與營業利益必須與交易所 OpenAPI 數值交叉吻合（換算後容差1元）。不同或缺值則撤回財報判定，保留來源與警示。
- 補充歷史行情使用 Yahoo / yfinance，明確標示第三方來源。OHLC 以相同股息/分割因子調整，再換算到末日原始收盤尺度。末日日期及原始收盤價須與官方行情一致；容差0.1%或0.02元取大者。
- 行情日期、財報期間、資料取得時間與快照產生時間分開；重新讀取每日紀錄不表示資料來源剛更新。
- 月營收暫作補充觀察。未完整取得歷史三個月資料，因此不把單月代替近三月，也不虛構近三月年增；未驗證月營收金額單位不參與金額門檻。

## v1 研究規則

以下為可查核的研究篩選，沒有推薦分數，未經回測驗證，不是下單訊號。

基本面5項全部符合才進首頁兩區：

1. 近四季營收 ≥ 新台幣10億元：排除營運規模極小者。
2. 近四季營收同比 ≥15%：確認跨季成長，避免單月基期波動。
3. 近四季營業利益率 >0：確認本業獲利。
4. 近四季營業現金流 >0：確認營運產生現金。
5. 近四季自由現金流 >0：定義為 OCF 減「取得不動產、廠房及設備」金額絕對值；不是減全部投資現金流。

財報期末不得未到期或超過210日；金融保險（17）、建材營造（14）暫不套一般企業規則。嚴格大於0不接受0，缺值不補0。

技術面4項全部符合進第一區；其餘基本面已通過者進第二區：

- 還原收盤 > MA50 > MA200。
- MA50、MA200各自高於20個交易日前。
- 近20日平均原始收盤×成交股數 ≥2,000萬元，**這是成交金額近似值**。
- 額外資料閘門：至少220日、官方行情不超過5日、與官方末日價核對一致。

2026-09-16初次歷史樣本：1,979候選、1,971取得歷史、1,960至少220日、1,936末日與官方一致。1,969筆可算20日成交近似值：中位數約1,082萬元、25分位約163萬元、825筆達2,000萬元。此分布說明門檻涵義，不證明績效；營收10億元是規模研究下限，非回測最適值。

進場觀察使用距離≤2%、RR≥2、收復前高、成交量與回測確認。成交密集區為日線近似，非真實持倉成本。只有雙重通過且全部進場條件通過才顯示READY。處置、停止交易、重大訊息仍需至交易所另查，尚無完整自動交易限制閘門。

## 儲存與排程

- VPS資料：`/var/lib/moneytools/taiwan`；公開版本：`/var/www/moneytools-tw/current`；HTTP：`/data/tw/dashboard.json`、`stocks/<symbol>.json`、`history.json`。
- `taiwan_sources.py`、`taiwan_financials.py`、`taiwan_history.py`取得資料；`taiwan_build.py`核對並原子發布。
- 財報最多8個worker，全域每秒最多1次請求、每次最多10家公司、每輪最多2500次；每日快取去重。遇限流或禁止存取停止新請求，不繞過封鎖。
- 來源全批處理完且營收覆蓋至少70%、歷史與官方最新價日期一致且有效的覆蓋至少80%才可發布；正常資料不足者仍逐檔標示，不放寬個股判定。`--allow-partial`僅供本機開發預覽，禁止正式發布使用。
- `moneytools-taiwan-scan.timer`：週一至五台北16:30起，每小時檢查至22:30。分別比較上市、上櫃官方最新行情日，任一市場有新資料才跑；休市不製造新掃描。這不是獨立交易所日曆推算。
- 完成鎖與排程安裝不代表未來掃描已實際成功；需查 `last-success.json`、journal與公開資料時間。
- 公開版本保留3份，觀察歷史保留30日；官方與財報私有快取保留45日。每日更新不推GitHub、不觸發Vercel建置。
- 初次完整快照建立基準，不全部標today；前次資料不足恢復不能冒充確定的新符合。兩市場收藏使用不同localStorage key。

## 驗證

`python -m unittest discover -s tests -q` 包含解析、零與缺值、跨年TTM、口徑差異、官方交叉核對、嚴格邊界、價格不一致、today與版本保留。前端需另執行TypeScript、完整建置、手機390/iPad768/桌面1440互動驗證。

部署時先備份既有設定，僅新增台股路由及服務。Vercel仍只有靜態前端；原始資料與Python不打包。保持美股API與排程不變，集中一次推送與部署，發布前分別核對帳號100次及專案20次的當日建置限制。
