# 集中發布與每日資料更新

每批完成適當測試後即可集中發布，不需等待固定時段。另已在維護任務設定每日台北 18:00 檢查待發布版本；沒有變更不新增空提交或重複部署。

程式 push 由 CI 驗證並由 Vercel 整合部署，不自動重掃全池。每日資料僅由 NYSE 收盤後 75 分鐘的 schedule 或明確的 workflow_dispatch 啟動。手動更新仍可用；排程保留夏令時間、假日及提早收盤判斷。

每天最多 20 次 Vercel 建置，包含資料更新、分支建置與重試。推送前核對當日用量，無法確認或額度不足則保留待發布版本並回報；此限制尚未自動硬性實作。手動掃描成功可能產生資料提交與一次部署，也需先確認用量。

這次流程調整不修改分析規則、行情或歷史。程式配置與實際觀察到的排程執行結果需分開回報。
